# Changelog

## 0.1.1

- After a game update, a hook that can no longer be placed is logged as an error, so the Mod Manager can mark the mod as maybe needing an update.
- Made for Survival Log 1.1.19131.

## 0.1.0

First build. A Mods menu entry that, before the disaster, searches every container and uses every daily reward interaction in the store you are in. Three modes (walk and open each bag, walk and take everything, take everything in place). Any order you give during a run stops it. Settings change in game on the Mod Manager's Mods screen with no restart, and the Mods screen shows the mod's name, description and links.
