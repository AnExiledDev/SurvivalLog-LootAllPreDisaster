# Changelog

## 0.1.0

First build. A Mods menu entry that, before the disaster, searches every container and uses every daily reward interaction in the store you are in. Three modes (walk and open each bag, walk and take everything, take everything in place) and an optional instant action time. Settings change in game on the Mod Manager's Mods screen with no restart, and the Mods screen shows the mod's name, description and links.
