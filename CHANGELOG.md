# Changelog

## 0.1.1

- After a game update, Mod Manager can tell you if this mod may need an update.
- Made for Survival Log 1.1.19131.

## 0.1.0

- First release.
- Before the disaster, a new entry in the inventory's Mods menu searches every container in the store you're in and uses every daily reward there.
- Three modes: walk to each one and loot it by hand, walk to each one and take everything, or take everything without walking.
- Any order you give during a run stops it.
- Settings can be changed in game on Mod Manager's Mods screen, with no restart.
